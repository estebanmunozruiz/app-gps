# GPS Agricola

Prototipo web de guia GPS agricola para celular, tablet o computador.

## Uso

Abrir `index.html` desde GitHub Pages o desde un servidor local.

Funciones principales:

- Vista satelital.
- Ubicacion GPS.
- Linea A-B.
- Pasadas paralelas segun ancho de implemento.
- Registro de recorrido y area aproximada.
- Modo demo.
- Ubicacion manual por latitud y longitud.

## Nota de precision

El GPS del celular puede variar varios metros. Para uso agricola de mayor precision se recomienda evaluar un receptor GNSS externo o RTK.
